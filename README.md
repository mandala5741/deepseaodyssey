# 🌊 深海掠夺者 (Deep Sea Odyssey)

**深海掠夺者**是一款基于Agent驱动的深海冒险MUD（Multi-User Dungeon）游戏，融合了角色扮演、策略战斗、资源收集和社交互动等元素。玩家将在神秘的深海世界中展开冒险，探索未知海域，收集珍稀生物，提升角色实力，与其他玩家竞技互动。

## 项目说明

本项目采用现代化的Web技术栈构建：
- **后端框架**：Python Flask提供RESTful API服务
- **数据库**：PostgreSQL存储游戏数据，Redis提供缓存加速
- **前端技术**：HTML5 + JavaScript + CSS3构建响应式游戏界面
- **部署环境**：支持本地开发和线上部署，默认服务端口5000

游戏支持多玩家同时在线，具备完整的数据持久化机制，确保玩家进度安全保存。

## 核心玩法

### 🎯 角色成长
- **属性培养**：通过战斗、任务和使用道具提升六维属性（钳力、甲壳、游速、虾慧、体力、魔法值）
- **装备系统**：收集武器、防具，强化装备提升战力，最高+5级强化
- **技能学习**：各门派拥有独特技能树，策略性搭配战斗技能

### 🌊 深海探索
- **海域冒险**：四大特色海域（珊瑚礁域、幽暗深渊、炽热岩浆、极寒冰窟）自由切换
- **生物收集**：100+种海洋生物，击败后获得标本永久收藏到收纳袋
- **物品拾取**：从普通贝壳到传说装备，五种稀有度等级丰富掉落系统

### ⚔️ 战斗竞技
- **PVP对战**：与其他玩家实时对战，展示策略和操作技巧
- **世界BOSS**：团队合作挑战强力BOSS，争夺稀有奖励和专属卡片
- **战力系统**：基于属性的战力计算公式：`战力 = 基础战力 + 攻击*2 + 防御 + 速度 + 幸运*3`

### 🏛️ 社交系统
- **门派加入**：选择心仪门派，获得专属加成和技能，六大门派各具特色
- **拍卖交易**：玩家间自由交易装备和物品，支持物品、装备、神器三种类型
- **邮件通信**：系统通知和玩家间消息传递，支持附件发送

### 💰 经济体系
- **货币系统**：金贝作为主要交易货币，通过任务、战斗、交易获得
- **商店购物**：购买装备、消耗品和永久属性道具（如钳力灵石、甲壳水晶等）
- **装备强化**：投入1000银贝/次强化装备，提升攻击+1500、防御+1500、生命+1500/级

## 游戏特色

- 🦐 **六维属性系统**：钳力、甲壳、游速、虾慧、体力、魔法值，全方位角色成长
- ⚔️ **六大门派**：铁钳派、玄甲派、幻影派、智谋派、海神派、深渊派，各具独特加成
- 🗺️ **多样化玩法**：深海探索、巡逻任务、义工服务、PVP战斗、世界BOSS挑战
- 💰 **经济系统**：商店购买、拍卖行交易、装备强化、神器收集
- 💾 **数据持久化**：PostgreSQL数据库存储、Redis缓存加速、自动存档机制
- 🌊 **深海冒险**：四大海域探索、100+种海洋生物收集、标本收纳系统
- 🛡️ **保护机制**：新手保护盾、战力平衡系统、安全战斗环境

## 运行方式

```bash
cd /data/games/deep_sea_odyssey
python3 game.py
```

## 游戏指令

| 指令 | 说明 |
|------|------|
| 状态 / stats | 查看角色六维属性和当前状态 |
| 巡逻 / patrol | 执行巡逻任务，获取经验和随机奖励 |
| 义工 / chore | 做义工赚取金贝，有冷却时间限制 |
| 商店 / shop | 打开商店购买装备和消耗品 |
| 背包 / inv | 查看背包物品和装备 |
| 使用 [物品] | 使用背包中的物品 |
| 技能 / skills | 查看已学技能和技能点 |
| 学习 [技能] | 消耗技能点学习新技能 |
| 战斗 / battle | 挑战其他玩家或NPC |
| 门派 / faction | 查看门派信息和加入门派 |
| 休息 / rest | 恢复体力值 |
| 冥想 / meditate | 恢复HP和MP |
| 对话 / talk | 与NPC对话获取任务 |
| 保存 / save | 手动保存游戏进度 |
| 退出 / quit | 安全退出游戏 |

## 门派系统

| 门派 | 属性要求 | 被动效果 | 特色技能 |
|------|---------|---------|---------|
| 铁钳派 | 钳力≥8 | 暴击伤害+20% | 铁钳碎岩、力量爆发 |
| 玄甲派 | 甲壳≥8 | 伤害减免+15% | 甲壳护盾、反震攻击 |
| 幻影派 | 游速≥8 | 闪避率+15% | 影分身、疾速移动 |
| 智谋派 | 虾慧≥8 | 技能效果+20% | 智慧光环、法术强化 |
| 海神派 | 综合属性 | 水系技能增强 | 海神之怒、潮汐控制 |
| 深渊派 | 战斗经验 | 暗属性攻击 | 深渊威压、暗影突袭 |
